# Решать задачу в удобном для ревью виде

Сначала прочитай `~/.claude/skills/commit-review-core/RULES.md` — там формат, виды, порядок,
правила про хуки. Проект должен быть на Go, иначе скажи об этом и работай обычным образом.

## Шаги

1. **Уточнить** одним `AskUserQuestion` только то, что неизвестно: команда сборки (по умолчанию
   `go build -o /dev/null ./...`), нужны ли тесты в конце, ветка не master/main — точно ли коммитить сюда.
2. **Обзор — согласовать.** Изучи код минимально и покажи компактный обзор (RULES.md, «Обзор для
   пользователя»): топ-5 самых важных фич (топ-3, если это слишком сложно) в порядке выполнения —
   от простых и независимых к сложным — с 1–3 главными функциями каждой, остальные одной строкой.
   Фичи идут строго по очереди; технические коммиты (скелет, смена контракта) остаются внутри
   своей фичи; функции внутри фичи — от простых к сложным (`commitkind order`). Изменение
   маленькое (<~50 строк) и одного класса — один коммит. **Жди согласия** на фичи, порядок и
   главные функции; код до этого не трогай. Детальный список коммитов согласовывать не нужно.
3. **Исполнение по пунктам.** Для каждого: минимальная правка соответствующего класса (новый код — сначала скелет: типы и функции с заглушкой `panic("not implemented")`, затем по одной реализации на коммит) (включая все вызовы; в техническом — без логики, новый аргумент не используй) →
   `~/.claude/skills/commit-review-core/scripts/rr-commit.sh -m "[фича] [вид] тема" [--body "зачем"] -b "<сборка>" -- <файлы>`.
   Скрипт соберёт проект из индекса во временном каталоге, закоммитит через хуки и проверит тему. Не перечитывай дифф после
   коммита; если выяснилось, что пункты не разделить — объедини их и скажи об этом.
4. **Финал.** `commitkind check <база>..HEAD`, `commitkind overview <база>..HEAD` (обзор открывает отчёт), один раз `go vet ./...` и тесты (если просили),
   итог таблицей: хеш, итоговая тема, что внутри. Не пушь.

Пока рабочая копия содержит чужие незакоммиченные изменения — не включай их в коммиты
(`rr-commit.sh` коммитит только переданные файлы) и упомяни это.
